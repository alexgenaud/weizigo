## The headline verdict the operator is waiting for

**Is a loop sustainable under optimal play by both sides?**

- **3×3 (exhaustive): YES — forced.** The optimal-move subgraph (all optimal children kept,
  ties included) contains 54 cyclic SCCs / 4,550 states (of 47,456). **12 of those cycles
  (80 states) are genuinely FORCED**: every node on the cycle strictly prefers to stay —
  every alternative is strictly worse — so neither player will deviate. The other 42
  (4,470 states) are indifferent: an equally-optimal exit exists, so the loop is available,
  not compelled. Value is constant around all 54 (0 bad) and the tautology guard
  (V_p == Bellman-best) is 0/47,456 — the subgraph and the table agree.
- **4×4 (declared sample, seed 42, budget 150,000 nodes = 0.15% of the table): YES —
  available.** The sampled subgraph contains 6 cyclic SCCs / 24 states, all 4-cycles, all
  indifferent, value constant on all 6. **Zero forced cycles in the sample is a lower bound,
  not a finding** — whether 4×4 has a forced cycle is open, and needs a larger-sample or
  exhaustive run the 4 GB RSS guard did not allow.
- **The operator's "no problem to solve" case is therefore NOT established at 3×3.** At 3×3
  there exist positions where both players, playing optimally, are compelled to loop.
