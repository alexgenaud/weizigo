## 1. Setting

### 1.1 The game graph (from v1 §1–§2, standing)

A **state** is `S = (board, side, ko_point, passes)` with `board` a legal
Tromp–Taylor position on `n = w·h` cells, `side ∈ {Black, White}` to move,
`ko_point ∈ {none} ∪ cells` (basic-ko formalization **(i)**: the point
forbidden to the current player's first move, set only by a single-stone ko
capture, lifted after any other move), `passes ∈ {0, 1, 2}`.

Facts carried from v1 §1–§2 (A1/A2, audited and standing), used as hypotheses:

- **(A1-legal)** The legal-move set `Moves(S)` is a function of `S` alone.
  Pass is always legal, so **every non-terminal state has at least one
  successor**.
- **(A1-term)** `Terminal(S) ⇔ passes = 2`; the terminal payoff is
  `p(S) = area_score(board) ∈ ℤ ∩ [−n, +n]`, Black-positive.
- **(A1-ko/passes)** The successor tuple is a function of `(S, move)`:
  a stone move updates the goban, sets `ko_point` iff it is a single-stone ko
  capture per (i), and resets `passes` to 0; a pass leaves the goban, clears
  `ko_point`, and increments `passes`.

This makes a finite directed graph `G`: vertices = states, partitioned into
Black-to-move, White-to-move, and terminal; edges = moves. Everything below is
**pure finite-graph game theory** — no further Go-specific structure is used.
That is deliberate: the proof's validity must not depend on goban size
(per-goban epistemic independence applies to *empirical* results; this is a
structural argument in the ADR-0016 sense, and its hypotheses (A1-*) are
per-rule, not per-goban).

### 1.2 Plays, outcomes, guarantees

A **play** from `S` is a maximal path in `G` starting at `S`. By (A1-legal) a
play is either finite ending at a terminal, or infinite. The **outcome** of a
play is `p(t)` if it ends at terminal `t`, and the constant `T ∈ ℤ`,
**−n ≤ T ≤ +n**, if it is infinite. Black maximizes the outcome, White
minimizes it.

**Remark (no trigger — reviewer F2's boundary).** The rule as analyzed has
**no in-game repetition trigger**: a repeated position does not end the game;
the game simply continues, and `T` is the *value assigned to infinite plays*.
Cycles are valued, never detected. Any operational rule that *ends* the game
on some repetition condition (goban repeat, `(board, side)` repeat, move cap)
is a **different game**, and nothing in this document proves it has the same
value — see §6.2 and §9.2/§9.7.

A **strategy** for a player maps every finite history ending in a state owned
by that player to a successor. Strategies **may use full history** — we
quantify over all of them; Markovian sufficiency is a *conclusion* of this
proof (§6.1), never an assumption. A strategy pair `(σ_B, σ_W)` and a start
state determine a unique play, hence an outcome `o(σ_B, σ_W, S)`.

- Black **guarantees ≥ v** from `S` iff `∃σ_B ∀σ_W: o(σ_B, σ_W, S) ≥ v`.
- White **guarantees ≤ v** dually.
- `V_B(S) =` the largest `v` Black guarantees (well-defined: the guaranteed
  set is non-empty — every outcome is ≥ −n — downward closed, and bounded by
  +n). `V_W(S) =` the smallest `v` White guarantees, dually.

**Lemma 1.1 (weak duality).** `V_B(S) ≤ V_W(S)`.
*Proof.* Take σ_B guaranteeing ≥ V_B and σ_W guaranteeing ≤ V_W; the single
play they generate has one outcome `o`, and `V_B ≤ o ≤ V_W`. ∎

The game is **determined** at `S` if `V_B(S) = V_W(S) =: V(S)`. Theorem 3.1
proves determinacy everywhere and computes `V`.

## 2. Attractors, traps, and the forced-termination values f, g

### 2.1 Attractors

For a set `X` of terminal states, define the **Black attractor** `Attr_B(X)`
as the limit of the increasing sequence

```
A_0 = X
A_{k+1} = A_k ∪ { S non-terminal, Black to move : some successor ∈ A_k }
              ∪ { S non-terminal, White to move : every successor ∈ A_k }
```

Finite graph ⇒ stabilizes at some `A_r = Attr_B(X)`. The **rank** of
`S ∈ Attr_B(X)` is the least `k` with `S ∈ A_k`. `Attr_W(X)` is defined
dually (∃ at White nodes, ∀ at Black nodes).

**Lemma 2.1 (attractor soundness).** If `S ∈ Attr_B(X)` with rank `k`, Black
has a positional strategy such that every play from `S` reaches `X` within
`k` moves — against **every** White strategy, history-dependent or not.
*Proof.* Induction on `k`. `k = 0`: `S ∈ X`, zero moves. `k+1`: if Black to
move, some successor has rank ≤ k; the strategy plays it. If White to move,
*every* successor has rank ≤ k (that is the ∀ in the definition), so any White
choice lands at rank ≤ k. Apply the inductive hypothesis. The choice depends
only on the current state, so the strategy is positional. ∎

**Lemma 2.2 (trap).** If `S ∉ Attr_B(X)`, White has a positional strategy
ensuring the play **never enters `X`**.
*Proof.* Let `U` be the complement of `Attr_B(X)`. A White node `S ∈ U`: the
∀-clause says `S ∈ Attr_B(X)` iff **every** successor is in it; `S ∈ U`
therefore means **some** successor is in `U` — White plays that successor. A
Black node `S ∈ U`: the ∃-clause says `S ∈ Attr_B(X)` iff **some** successor
is in it; `S ∈ U` therefore means **no** successor of a Black `U`-node is in
`Attr_B(X)` — every Black move from `U` stays in `U` regardless of what Black
wants. Terminals in `U` are not in `X` (since `X ⊆ A_0`). So with White
playing his `U`-preserving successor at his own nodes, the play never leaves
`U`, hence never enters `X`. ∎

(The load-bearing step is the Black-node closure: **the ∃-clause closes Black
`U`-nodes under *all* their successors.** That is R1 in §10, and the reviewer
attacked it and could not break it.)

### 2.2 The forced-termination values

For `v ∈ ℤ ∩ [−n, n]` let `Term_{≥v}` = terminals with payoff ≥ v, `Term_{≤v}`
dually.

- `f(S) := max { v : S ∈ Attr_B(Term_{≥v}) }`, and `f(S) := −∞` if
  `S ∉ Attr_B(Term_{≥−n})` — i.e. if Black cannot force termination at all
  (note `Term_{≥−n}` is *all* terminals).
- `g(S) := min { v : S ∈ Attr_W(Term_{≤v}) }`, and `g(S) := +∞` if White
  cannot force termination.

Well-defined by monotonicity: `v ≤ v' ⇒ Term_{≥v'} ⊆ Term_{≥v} ⇒
Attr_B(Term_{≥v'}) ⊆ Attr_B(Term_{≥v})`.

**Lemma 2.3 (compatibility).** If `f(S)` and `g(S)` are both finite,
`f(S) ≤ g(S)`.
*Proof.* Black's Lemma-2.1 strategy for `Term_{≥f}` forces every play to end
at a terminal with payoff ≥ f, against any White strategy; White's dual
strategy forces every play to end with payoff ≤ g. Play them against each
other: one play, one final terminal `t`, `f ≤ p(t) ≤ g`. ∎

## 3. The value theorem

Define, with the conventions `max(−∞, x) = x`, `min(+∞, x) = x`:

```
med(S) := max( f(S), min(T, g(S)) )
```

When `f ≤ g` (always, by Lemma 2.3 and the conventions) this equals the
median of the three quantities `f(S), T, g(S)`.

**Theorem 3.1 (determinacy and value).** For every state `S`,
`V_B(S) = V_W(S) = med(S)`.

*Proof.* By Lemma 1.1 it suffices to show (a) Black guarantees ≥ `med(S)` and
(b) White guarantees ≤ `med(S)`.

**(a1) Black guarantees ≥ f(S).** If `f = −∞`, vacuous. Else the Lemma-2.1
strategy for `Term_{≥f}` forces a finite play ending in a terminal of payoff
≥ f.

**(a2) Black guarantees ≥ min(T, g(S)).** Let `v = min(T, g)`. If `v = −∞`
vacuous (`g` finite ⇒ `v` finite; `g = +∞ ⇒ v = T`). Claim
`S ∉ Attr_W(Term_{≤ v−1})`: otherwise `g(S) ≤ v − 1 < v ≤ g(S)`,
contradiction. By Lemma 2.2 (dual form, White↔Black swapped), Black can keep
the play out of `Term_{≤ v−1}` forever. Under that strategy every play either
ends at a terminal with payoff ≥ v, or is infinite with outcome `T ≥ min(T,g)
= v`. Either way ≥ v.

By (a1), (a2): `V_B ≥ max(f, min(T, g)) = med`.

**(b1) White guarantees ≤ g(S)** — dual of (a1).

**(b2) White guarantees ≤ max(T, f(S)).** Let `u = max(T, f)`; note `u ≤ +n`
always (`T ≤ +n`, and `f ≤ +n` or `−∞` — reviewer F5 removed a spurious
`u = +∞` case here). `S ∉ Attr_B(Term_{≥ u+1})` (else `f ≥ u + 1 > u ≥ f`;
for `u = +n` the set `Term_{≥ n+1}` is empty and its attractor too). By Lemma 2.2,
White keeps the play out of `Term_{≥ u+1}` forever: every play ends ≤ u or is
infinite with outcome `T ≤ u`.

By (b1), (b2): `V_W ≤ min(g, max(T, f))`.

**(c) The two bounds meet.** `f ≤ g` always: Lemma 2.3 for both finite, and
trivially when either is infinite (reviewer F6). Then both
`max(f, min(T, g))` and `min(g, max(T, f))` equal the median of `{f, T, g}` —
check the trichotomy of `T` against `[f, g]`:

| ordering | `max(f, min(T,g))` | `min(g, max(T,f))` |
|---|---|---|
| `T ≤ f ≤ g` | `max(f, T) = f` | `min(g, f) = f` |
| `f ≤ T ≤ g` | `max(f, T) = T` | `min(g, T) = T` |
| `f ≤ g ≤ T` | `max(f, g) = g` | `min(g, T·) = g` |

with the `±∞` conventions folding in (e.g. `f = −∞, g = +∞`: both sides are
`T`). So `med ≤ V_B ≤ V_W ≤ med`. ∎

**No external theorem was used.** Lemmas 2.1–2.3 and Theorem 3.1 are proven
from the graph definitions. The chess-tablebase / Fraenkel–Simonson /
Gale–Stewart references of v1 §3 remain as *context*, not as load-bearing
citations — this is the fix for audit F2: "the true game value = V_A" is no
longer cited, it is proven (here `V_A` *is* `med`, computed by the attractor
family, and Theorem 3.1 says the true value equals it).

## 4. The crucial lemma: L and H *are* the attractor values

### 4.1 The Bellman fixpoints (matching ADR-0009)

Let `D = ℤ ∩ [−n, +n]` and define `Φ` on `D`-valued tables:

```
(ΦX)(S) = p(S)                        S terminal
        = max over successors X(S')   S non-terminal, Black to move
        = min over successors X(S')   S non-terminal, White to move
```

`Φ` is monotone. Define:

- `L` := the limit of `L_0 ≤ L_1 ≤ …`, where `L_0(S) = p(S)` on terminals and
  `−n` elsewhere, `L_{k+1} = Φ(L_k)`. (Increasing since `L_0 ≤ Φ(L_0)`;
  finite lattice ⇒ converges; the limit is the **least** fixpoint of `Φ`,
  since any fixpoint `Y` satisfies `Y ≥ L_0`, hence `Y = Φ^k(Y) ≥ Φ^k(L_0)`
  for all k.)
- `H` := the limit of the dual decreasing iteration from `+n`; the
  **greatest** fixpoint.

This is exactly ADR-0009's `converge` (L seeded −n swept up, H seeded +n swept
down, **same operator, Black max / White min in both**). ⚠️ v1 §4.2 stated
the H recurrence with max/min **swapped** ("side Black: min, side White:
max") — that is a transcription error against ADR-0009 and against what H
must be; recorded in §9.3 so no implementer copies it.

### 4.2 The identification

**Theorem 4.1.** For every state `S`:
`L(S) = max(f(S), −n)` and `H(S) = min(g(S), +n)`
(conventions: `max(−∞, −n) = −n`, `min(+∞, +n) = +n`).

*Proof of `L ≥ max(f, −n)`.* `L ≥ −n` by the lattice. Suppose `f(S) = v` finite;
show `L(S) ≥ v` by induction on the attractor stage `k` with
`S ∈ A_k` (attractor of `Term_{≥v}`), using only that `L` is a fixpoint:
`k = 0`: terminal, `L = p ≥ v`. Black node in `A_{k+1}`: some successor in
`A_k` has `L ≥ v` (IH), and `L(S) = max ≥ v`. White node in `A_{k+1}`: every
successor is in `A_k`, each with `L ≥ v` (IH), so `L(S) = min ≥ v`. ∎

*Proof of `L ≤ max(f, −n)`.* It suffices to show `L(S) = v > −n ⇒ f(S) ≥ v`,
i.e. (by definition of `f`) `S ∈ Attr_B(Term_{≥v})`. Prove by induction on
`k` the monotone statement: **if `L_k(S) ≥ v > −n` then
`S ∈ A_k(Term_{≥v})`** (the k-th attractor stage). `k = 0`: only terminals
have `L_0 > −n`, and a terminal with `p ≥ v` is in `A_0`. Step
`L_{k+1} = Φ(L_k)`: terminal — as in the base. Black node with
`L_{k+1}(S) ≥ v > −n`: the max over successors is ≥ v, so some successor `S'`
has `L_k(S') ≥ v > −n`; by IH `S' ∈ A_k`, so `S ∈ A_{k+1}` by the ∃-clause.
White node with `L_{k+1}(S) ≥ v > −n`: the *min* over successors is
≥ v > −n, so **every** successor has `L_k ≥ v > −n`; by IH every successor is
in `A_k`, so `S ∈ A_{k+1}` by the ∀-clause. Since `L = L_k` for some finite
k, done. (Reviewer F3: an earlier draft concluded "Black can force a terminal
≥ v" and passed silently from *can-force* to *attractor membership* — a true
but uncited converse of Lemma 2.1. This version proves membership directly,
as the reviewer prescribed.) ∎

`H = min(g, +n)` is the exact dual. ∎

**Remark 4.2 — what `L` is *not*.** v1's "crucial lemma" read `L` as "the
value under cycle-free play" and justified it by "by Knaster–Tarski, L is the
least fixed point, which corresponds to 'consider only cycle-free plays.'"
Knaster–Tarski gives existence, not that reading — audit F2, and the same
step-type that killed C3. Theorem 4.1 **replaces** that reading: `L` is
**Black's forced-termination value** — the best payoff Black can force *while
also forcing the game to end*, against arbitrary (history-dependent) White
play. Plays under the forcing strategy happen never to revisit a state
(attractor rank strictly decreases), but cycle-freeness of plays is a
by-product, not the definition, and no claim about "the set of cycle-free
plays" is made or needed. Note also why this is a theorem *here* when
ADR-0009's honesty clause could not make it one *there*: the ADR-0009 leak
came from PSK bans — history-dependent legality — breaking the memoryless
argument. Under the present rule, legality is a function of the state tuple
(A1-legal), and Lemmas 2.1/4.1 go through with no leak.

## 5. The trichotomy, resolved — and the corrected rule

**Theorem 5.1 (post-processing rule).** For every state `S`, with
`−n ≤ T ≤ +n`:

```
V(S) = max( L(S), min(T, H(S)) )   —  equivalently, median(L(S), T, H(S)).
```

*Proof.* `V = med(f, T, g)` (Theorem 3.1) and `L = max(f, −n)`,
`H = min(g, +n)` (Theorem 4.1). If `f` is finite then `L = f` (payoffs lie in
`[−n, n]`); if `f = −∞` then `L = −n`, and since `T ≥ −n` and `g ≥ −n`,
`median(−n, T, g∧n)` = `min(T, g∧n)` = `median(−∞, T, g∧n)` — the clamp
changes nothing. Dually for `g = +∞` with `T ≤ +n`. So
`median(L, T, H) = median(f, T, g) = V`, and for `L ≤ H` the median equals
`max(L, min(T, H))`. ∎

(The hypothesis `−n ≤ T ≤ +n` is essential to the clamp-robustness — a `T`
outside the terminal payoff range would need genuine `±∞` sentinels. For this
project `T = 0`, comfortably inside.)

### 5.1 All three orderings (audit F1, answered head-on)

For `L < H` (the only interesting case; `L = H ⇒ V = L` immediately):

| ordering | `V` | why — who forces what |
|---|---|---|
| `L ≤ T ≤ H` | `T` | Black avoids `Attr_W(Term_{≤T−1})` forever (a2): every terminal reached ≥ T, cycling = T. White dually avoids `Attr_B(Term_{≥T+1})`. Neither can break past the tie; both can secure it. |
| `T < L < H` | **`L`, not `T`** | Black forces a terminal ≥ L by the attractor strategy — **never cycles, never needs to**. White holds Black to L by trapping outside `Attr_B(Term_{≥L+1})`: inside that trap every terminal is ≤ L **and the cycle is worth `T < L`** — both outcomes fine for White. |
| `L < H < T` | **`H`, not `T`** | symmetric: White forces ≤ H; Black holds White to H by trapping outside `Attr_W(Term_{≤H−1})`, where every terminal is ≥ H **and the cycle is worth `T > H`** — both fine for Black. |

**The audit's question — "which way does the cycle-dependence resolve? that
turns on who can force a cycle, and neither fixpoint carries that
information" — is answered by dissolving it.** Nobody needs to *force a
cycle*. What each player needs is *cycle-or-acceptable-terminal*, and that is
exactly what a trap (Lemma 2.2) provides unconditionally. The information the
audit thought was missing from `L` and `H` — who can force infinite play —
is never consulted: the position of `T` relative to `[L, H]` alone determines
which player's trap is the binding one. And by Theorem 4.1 the attractor
computation the audit expected to be *additionally* required **is `L` and `H`
themselves** — the integer-valued fixpoints compute every threshold attractor
at once. There is no third computation left to run.

### 5.2 Where v1's rule is wrong, exactly

v1 §4.3 asserted `L < H ⇒ V = T`. By Theorem 5.1 that is correct **iff
`T ∈ [L, H]`**. It is false on every state with `L < H` and `T < L` (true
value `L`) or `H < T` (true value `H`). v1's parenthetical "if `L < T` is not
the case, then `L = T`" is likewise false — nothing stops `L > T`.

### 5.3 Concrete counterexample to v1's rule (calibration witness)

Not Go-specific — the v1 claim was made for the general class, so a
class-level witness kills it. Four states: `S0` (Black to move), `S1` (White
to move), terminals `t1` (payoff +1), `t3` (payoff +3). Edges:
`S0 → t1`, `S0 → S1`; `S1 → S0`, `S1 → t3`. Tie `T = 0`.

- `f(S0)`: Black forces `t1` directly ⇒ `f = 1` (Black cannot force `t3`:
  White at `S1` returns to `S0`). `L(S0) = 1`.
- `g(S0)`: `Attr_W(Term_{≤1}) = {t1}` only (`S1`'s escape `t3 ∉`, and `S0`
  needs *both* successors in — `S1` never enters). `Attr_W(Term_{≤3})` = all.
  ⇒ `g = 3`, `H(S0) = 3`.
- `L = 1 < 3 = H`, `T = 0`: **v1's rule pins `V(S0) = 0`.**
- Truth: Black plays `t1` and banks +1; entering `S1` lets White cycle
  (worth 0 < 1) — so `V(S0) = 1 = median(1, 0, 3)`. The corrected rule gives
  1. **v1's rule is off by the full tie-vs-guarantee gap on this state.**

How often `T ∉ [L, H] ∧ L < H` occurs on *real Go gobans* is an empirical
question — EXP-4 must report that census ("pin census", §6.3) per goban. Zero
at a given size would mean the two rules coincide *there*; it would not
rescue v1's rule as a theorem.

## 6. Consequences

### 6.1 Markovian sufficiency (QA-023's core, earned)

By (A1-legal/term/ko/passes) the continuation game from a state `S` — its
legal moves, successor states, terminal payoffs, and (because `T` is a
**constant**) the value of its infinite plays — is the same game regardless of
the history that arrived at `S`. By Theorem 3.1 that game has a well-defined
value `V(S)`; by Theorem 5.1 it is computable from two Bellman fixpoints on
the state graph. **No component consults history; hence
`(board, side, ko_point, passes)` is a sufficient Markovian state for exact
solving under this rule.** Contrast score-on-cycle: there the outcome of a
continuation play depends on which gobans the *arrival path* has already
visited, so the continuation game itself differs by history and no
state-graph value exists — fully consistent with the RETRO_CYCLE foreclosure
(byte-identical blowup with PSK) and the RETRO_PLY foreclosure (any verdict
that must *identify* the repeated goban drags full history into the key).
This proof does not weaken those foreclosures; it locates the exact boundary:
**the verdict being a constant is what removes history from the payoff; the
Markovian ko/passes components are what remove it from legality.**

### 6.2 A provably sound history-carried evaluator for EXP-2B

The Part B probe must evaluate a state "with history carried". For this rule
the natural bounded evaluator is **first-revisit truncation**: search the
game tree from `S`, and when a path revisits a state already on that path,
score that leaf `T`; terminals score `p`.

**Theorem 6.1 (truncation soundness).** Minimax on the first-revisit-truncated
tree from `S` equals `V(S)`.
*Proof.* The truncated tree is finite (path lengths ≤ number of states + 1).
It suffices that each player's Theorem-3.1 strategy secures `V(S)` in the
truncated game too. Case `V = L > T` (trichotomy row 2): Black's attractor
strategy strictly decreases rank, so its plays never revisit a state — no
truncation occurs on them — and they end at terminals ≥ L; White's trap keeps
the play where terminals are ≤ L and any truncated leaf is `T < L` — both ≤ L.
Case `V = T`: each player's trap yields plays whose terminals are on the
right side of `T` and whose truncated leaves are exactly `T`. Case `V = H < T`
symmetric to row 2. In every case Black secures ≥ V and White ≤ V on the
truncated tree. ∎

Four probe-design consequences, stated so EXP-2B does not have to rediscover
them. The first two are the reviewer's F1 and F2 — both GAP-severity, both
repaired here in writing as the review demanded:

1. **(Reviewer F1 — do NOT memoize truncated values by state.)** Theorem 6.1
   equates only the **root** value with `V(S)`. The minimax value of a
   truncated **subtree** at an interior node depends on the path above it.
   The reviewer's counterexample, on the §5.3 gadget: evaluate `S1` inside
   the tree rooted at `S0` (so `S0` is on the path) — White chooses
   `min(p(t3) = 3, revisit S0 ⇒ leaf T = 0) = 0`; but `V(S1) =
   median(f=1, T=0, g=3) = 1`. A transposition table caching `S1 ↦ 0` and
   reusing it on a path not containing `S0` is wrong by a full point. **This
   is exactly the Graph History Interaction failure mode that killed
   RETRO_PLY and RETRO_CYCLE.** The constant-`T` rule escapes it only via
   the §4–§5 fixpoint computation (which never consults a path), or via
   Theorem 6.1 run with **no state-keyed caching** of truncated values.
2. **(Reviewer F2 — the truncation key is the full state tuple.)**
   Theorem 6.1 is proven for revisits of the full
   `(board, side, ko_point, passes)` tuple only. A truncation keyed on
   `board` or `(board, side)` repetition defines a **different evaluator**
   (a position can recur with a different `ko_point` or `passes`, changing
   the continuation), and its agreement with `V` is **unproven**. Implement
   the tuple key, or first prove the trigger-equivalence.
3. Truncate only on revisits *within the continuation from the probed
   state* — truncating against gobans in the *arrival prefix* would build a
   history-dependent evaluator and would test the probe, not the rule.
4. Given Theorem 6.1, a value disagreement across arrival histories at the
   same state falsifies **(A1)** (some legality/termination case secretly
   consults history) or an implementation — either is decision-relevant,
   which is why the probe still has teeth even though §6.1 is proven: it is
   the empirical check on (A1), the one part of this proof that is
   Go-specific.

## 7. Re-cost of the reframe (the audit's "convenient conclusion" test)

The audit: *"If resolving the trichotomy requires knowing who can force a

Findings, honestly:

- **The one-line story survives, but v1's line was the wrong line.** The
  post-processing is still O(1) per state after the same two fixpoint sweeps —
  but it is `V = max(L, min(T, H))`, not "`L<H ⇒ T`". The attractor
  computation the audit anticipated **is** `L`/`H` (Theorem 4.1); it was
  already in the budget.
- **No cost increase versus the roadmap's plan.** The roadmap always required
  re-running `converge` on the new state graph (new legality, ko_point and
  passes in the state) — nothing here adds a third sweep or a per-threshold
  iteration. What v1's §4.3 *understated* is that the sweeps run on the
  **new** graph; no shipped PSK artifact's L/H columns can be reinterpreted
  into new-rule values by any post-processing, one-line or otherwise.
- **One real, bounded cost found**: the solved state carries `passes ∈ {0,1}`
  (§6.3.1) — up to 2× the EXP-3 census bytes at 4×4 (< 354 MB, versus the
  258 MB PSK artifact). EXP-3's GO on dense addressing is unaffected.
- **What dies**: the sentence in `roadmap-2026-07-28.md` §2 — "you resolve
  them by pinning to that value instead of shipping a bracket" — and QA-026's
  current wording. Both state v1's false rule. They mis-value exactly the
  `T ∉ [L, H]` states (§5.2); corrected wording is in §6.3.2. The correction
  is semantic, not budgetary.
- **One forbidden optimization (reviewer F1)**: any forward evaluator under
  this rule (the EXP-2B probe, spot-checks, a future finisher-like tool) must
  **not** cache first-revisit-truncated values by state — interior truncated
  values are path-dependent (§6.2 item 1). This costs the probe speed, not
  the build: the generation path is the fixpoint sweeps, which need no such
  cache.

## 8. Relation to the foreclosures (for the reviewer)

RETRO_CYCLE (score-on-cycle byte-identical to PSK) and RETRO_PLY (bounded
window still intractable) both fell to the same mechanism: their cycle verdict
is a function of *which goban repeated*, so evaluation must detect repeats,
so history enters the key. Under a constant verdict, **no cycle is ever
detected** — nothing in §2–§5 mentions a repeated goban; infinite play enters
the value only through the trap lemmas, which are properties of the graph

brief's phrase "cycles manifest as states that no finite path to a terminal
pins down" is made exact by Theorem 4.1 — such states are precisely those
with `L < H`, and their value is pinned by where `T` sits in `[L, H]`.
