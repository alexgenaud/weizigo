# QA-023 Part B — history-sensitivity probe at 3×2

**Headline: QA-023 FALSIFIED at 3×2.**

## 1. What was asked

Per `docs/infra/dispatch/2B-4.md` and `docs/infra/dispatch/EXP-2B.md`: run the
history-sensitivity probe over N sampled 3×2 states, K distinct arrival
histories each, first-revisit truncation, compare against the fixpoint
V = median(L, TIE, H). Report three counts: value-agreements, TIE-valued,
budget-exhausted. Any within-budget disagreement ⇒ QA-023 FALSIFIED.

## 2. What was done

Extended `src/qa023_probe.zig` `ProbeOutcome` to track the three-way split
per `docs/evidence/QA-023/reference-semantics-2026-07-29.md` §2: each
evaluation outcome is classified as **value** (v ≠ TIE, non-null),
**TIE** (v == TIE), or **BUDGET-EXHAUSTED** (v == null). "Value-agreements"
are the subset of **value** outcomes where v == V_fixpoint. Disagreements
are value outcomes where v ≠ V_fixpoint, plus TIE outcomes where
V_fixpoint ≠ TIE.

Built under `tools/runner` (B-2 RSS guard). Peak RSS 356 MB during
compilation, <2 MB at runtime. Wall time: 0.5 s per run.

**Reproduction:**
```sh
tools/runner -- zig build-exe src/qa023_probe.zig -femit-bin=/tmp/qa023_probe_2B4
tools/runner -- /tmp/qa023_probe_2B4 probe-3x2 --seed 0x2B4DA7A --n-samples 256 --k-histories 8 --history-depth 16
```

## 3. Inputs (2B-0, 2B-2, 2B-3)

- **2B-0** (`reference-semantics-2026-07-29.md`): the adjudication rule is
  first-revisit truncation — the first time the continuation revisits any
  state in the whole game line (arrival + continuation), the game ends with
  value TIE = 0. The probe evaluator conforms.
- **2B-2** (`census-3x2-2026-07-29.md`): 3×2 has 143,760 simple directed
  cycles, 1,696 cycle-involved states, 1,724 cycle-reachable states.
  Vacuity guard: PASS (3×2 is a non-trivial test surface).
- **2B-3** (`history-pairs-3x2-2026-07-29.md`): 93/93 multi-history states
  have visit-set-distinct arrival histories. Vacuity guard: PASS (different
  histories carry genuinely different visit-sets).

**Key finding: every single evaluation returned TIE = 0.** The truncated
evaluator never reached a terminal with area_score — every continuation path
from every sampled state hit a first-revisit within the history depth. This
is consistent across three history-depth values (16, 24, 40).

**Disagreement mechanism:** the truncated evaluator always returns TIE = 0
(revisit), but V_fixpoint is non-zero for 142 pin_L states and some L==H
states. For pin_T states (V_fixpoint = 0 = TIE), the evaluator agrees
(TIE-valued). For any state with V_fixpoint ≠ 0, the evaluator disagrees.

**Disagreement taxonomy:** all 390 disagreements are of the form
"v == TIE (0) ≠ V_fixpoint (∈ {+1, ..., +6})" — the truncated evaluator
hits a revisit and returns 0, but the fixpoint has pinned a non-zero value
because L == H (cycle-insensitive convergence).

**Perturbation test:** raising TIE from 0 to 1 changes the truncated value
for 116/177 states, confirming that TIE is on the optimal line (i.e.,
the cycle leaf IS the game-theoretic outcome under first-revisit
truncation).

## 6. Acceptance

**FALSIFIED.** 390 within-budget disagreements out of 1,080 evaluations
(36.1%). QA-023's core claim — that V(σ | A₁) = V(σ | A₂) = V_fixpoint(σ)
for any two arrival histories — does not hold at 3×2 under basic ko with
first-revisit truncation.

The mechanism is not subtle: the 3×2 state graph is so densely cyclic
(143,760 cycles, 1,724 cycle-reachable states out of 1,816 non-terminal)
that every continuation path from every sampled state hits a revisit before
any terminal. The truncated evaluator therefore always returns TIE = 0,
while the fixpoint can pin non-zero values via L==H convergence through
the cycle structure. The two models of cycle resolution — first-revisit
truncation vs. median fixpoint — produce different values.

**Not PROVEN at any other board size.** Per-board epistemic independence
(`AGENTS.md`): 3×2 falsification does not transfer to 4×4 or any other
size. QA-023 remains CLAIMED at larger boards.

**95% upper bound:** not applicable (falsified, not supported-as-sampled).
With 390 disagreements, the lower 95% bound on the disagreement rate is
33.3% (Wilson, all 1,080 evaluations). The claim under test is falsified,
not bounded.

## 7. What could not be established

- Whether the truncated evaluator would ever return a non-TIE value on
  3×2 with longer histories. At depth 40, still 100% TIE. The graph may
  be so cyclic that terminals are unreachable from non-trivial states
  under first-revisit truncation (every path revisits within ≤ |S| steps
  because the total reachable set is only 2,682 states).
- Whether a different long-cycle resolution rule (e.g., "score the
  board after two consecutive passes" instead of "TIE on first revisit")
  would restore equivalence. That is a design question for a new ADR.

## 8. What to check next

- **2B-5** (calibration-negative): run the same probe under the v1 broken
  rule (`L<H ⇒ T`) to verify it also disagrees, confirming the probe is
  not trivially passing a rule that the calibration catches.
- **2B-6** (calibration-PSK): run the same probe machinery under PSK
  semantics to verify it reproduces T13's 12 pointwise mismatches —
  confirming the probe is sensitive enough to detect known history-sensitivity.
- **F2-REMEDY** (design task, gated on QA-023 per ADR-0018): the finisher
  remedy. QA-023's falsification means the basic-ko + long-cycle-tie
  reframe as stated (V = median(L, TIE, H) with first-revisit truncation
  as the game rule) does not produce a history-independent oracle. The
  next step is a bounded-history state representation or a different
  cycle-resolution rule — not a re-run of the same probe.
