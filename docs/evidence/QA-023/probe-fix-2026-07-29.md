## 2. Both fixes applied

### Defect 1: σ-in-arrival (was line ~1721)

`arrival_buf[0..arrival_len], arrival_len` → `arrival_buf[0..arrival_len - 1], arrival_len - 1`

Two call sites: the primary evaluation and the perturbation test. Per
`reference-semantics-2026-07-29.md` §1, the arrival visit-set is exclusive of σ;
the buffer at the construction site (`:1681-1712` area) is built inclusive. Fix:
pass `arrival_len - 1` and slice accordingly.

### Defect 2: scratch stack sizing (was line ~1593)

`gpa.alloc(HistoryEntry, params.history_depth + 4)` → `gpa.alloc(HistoryEntry, 4096)`

Continuation depth is bounded by the reachable state count (~2,622 at 3×2), not
by arrival depth. Scratch overflow now has its own counter and is reported
separately from budget exhaustion. Zero scratch overflows in all runs — the
original overflow was masked by defect 1 preventing any recursion.

### Hardcoded budget → `--node-budget` flag (was line ~3287)

`--node-budget N` flag added, default 100,000. Parsed alongside existing
`--seed`, `--n-samples`, `--k-histories`, `--history-depth`.

### Scratch overflow vs budget exhaustion

`truncated_value` now sets a `scratch_full: *bool` flag on scratch overflow.
The caller checks this flag to distinguish the two null-return paths. Two
separate counters in output: `budget-exhausted` and `scratch-overflow`.

## 4. Per-state adjudication of the 12 residual disagreements

All 24 disagreements in the 512-sample run come from 4 distinct states, each
evaluated with multiple distinct arrival histories. Every disagreement follows
the same pattern:

| state | V_fixpoint | truncated | side | passes | ko |
|---|---|---|---|---|---|
| (586,1,6,1) B: [B,␣,W,␣,B,W] | 0 | +1 | White | 1 | none |
| (534,1,6,1) B: [␣,B,W,B,␣,W] | 0 | +1 | White | 1 | none |
| (302,1,6,1) B: [W,B,␣,W,␣,B] | 0 | +1 | White | 1 | none |
| (146,1,6,1) B: [W,␣,B,W,B,␣] | 0 | +3 | White | 1 | none |

Additional states from depth 24: (566,1,6,1) with truncated=-6, (103,1,6,1)
with truncated=+3.

**Common properties:**
1. All are **White to move**, `passes == 1`, no ko point
2. V_fixpoint = **0** → the median rule pins TIE on every one
3. Truncated value is **non-zero** — the history-conditioned evaluator finds a definite value
4. On each state, **every within-budget history evaluates to the same value**
   (zero C1 failures within any state)

**Mechanism: over-pinning.** The median formula `V = max(L, min(TIE, H))` pins
TIE=0 whenever L < 0 < H. On these states, the truncated evaluator finds that
Black can force a win (+1 or +3) despite the fixpoint claiming the value is 0.
The fixpoint's L and H converge to values that bracket 0, but the
history-conditioned truth lies outside the bracket.

**Verdict: genuine C2 counterexamples.** These are not a third defect —
the evaluator correctly implements path-DFS with first-revisit truncation,
terminal area scoring, and budget accounting. The disagreement is between
the fixpoint's median formula and the history-conditioned value.

## 5. C1/C2 split

### C1 (Markovian state-sufficiency): UNTESTED-FOR-WANT-OF-CONTRAST

Zero within-budget disagreements among truncated values for the same state
across all eligible states at all depths tested (27 eligible in the 512-sample
run). However, per `2B-3-AUDIT` (DSPro, 2026-07-29, independent Python
verification), the DFS-only history generator **systematically misses short
arrival paths**:

- 28/30 states (93%): DFS misses the shortest path entirely
- 0/30 states: DFS includes any shortest path
- Avg shortest-path length: 5.1 moves; avg collected: 14.8 moves
- Avg pairwise shared prefix: 62%

Short paths are the most visit-set-diverse (every target with ≥2 shortest
paths has visit-set-distinct ones). The collected histories all share ~62% of
their prefixes and sit at depth ≥ 13. A "no C1 failure" result from this
generator means "no history-dependence among histories that share ~62% of
their prefixes" — a much weaker statement than "no history-dependence."

**C1 is not falsified, but it is also not properly tested.** A two-phase
generator (BFS for shortest paths + DFS for detours, then deliberate
short-vs-long pairing) would be needed for a proper test. This is scoped
out of 2B-PROBE-FIX.

### C2 (median formula): FALSIFIED

On every eligible state where the truncated value disagrees with the fixpoint,
all within-budget histories agree with each other. The median formula over-pins
TIE on states where the history-conditioned evaluator finds a definite value.
The formula `V = median(L, TIE, H)` does not hold for these states under
basic-ko first-revisit truncation.

- **Whether increasing the node budget changes the C2 count.** At 100,000

  value-agreements (and potentially more disagreements).
