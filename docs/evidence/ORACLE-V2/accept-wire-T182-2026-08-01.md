## What was done

### 1. Build-graph wiring

Added `oracle_v2_accept` test step to `build.zig`, chained into the `test`
step alongside the existing main test suite. `zig build test` now runs both.

### 2. A6 fixture (c) fix

The calibration check zeroed all DTT bytes in `corrupted[]` but then called
`checkDttNonConstant(entries, header)` — passing the **original** entry data
instead of the corrupted copy. The check always passed (the original has
non-constant DTT), making it a vacuously-true calibration — exactly the class
of defect the "positive control that exercises a parallel path" rule exists
to catch.

Fixed: extract `corrupted_entries` from the corrupted buffer and pass that
to `checkDttNonConstant`. Removed now-unused `entries` parameter from
`checkA6`.

### 3. Spec-faithful A9

Replaced the bare SHA-256 self-consistency check with a full reproducibility
verification per M1 design §7.1 determinism contract:

- **(a) reserved bytes zero** — already verified by `parseHeader`
- **(b) canonical sort order** — groups: `readGroupIndex`; entries: new scan
  within each group verifying `key_byte & 0xFE` is monotonic non-decreasing
  per §2.4
- **(c) no timestamps/metadata** — already verified by `parseHeader` (fixed
  header fields only)
- **(d) SHA-256 self-consistency** — embedded hash vs recomputed with slot
  zeroed (§4.2)

`A9Result` now reports: `sha256_ok`, `groups_sorted`, `entries_sorted`,
`entry_order_violations`, plus both hashes.

### 4. A5 stride/denominator

Added `stride` and `denominator` fields to `A5Result`. The output line now reads:
`A5 round-trip: checked={d} mismatches={d} stride={d} denominator={d}`
