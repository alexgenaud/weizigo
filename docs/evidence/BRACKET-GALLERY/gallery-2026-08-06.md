## 2. Operational definitions (the brief demands these be stated)

A state is `(colex, side, ko_point, passes)` — one table entry. "Ko" means two things, both counted:

- **ban** — the entry's own `ko` field is set (a capture created a ko one ply back; the recapture is forbidden);
- **shape** — the position carries a static ko shape (the production kernel rule: a move would capture exactly one stone, and the placed stone would end with one liberty and no friendly neighbours).

A state is **ko-carrying** if either holds.

- **Class 1 — single score with a ko in its past:** entry has `L == H` and its own `ko` field set. Verified per example: the ban cell carries the ko shape (`isKoShape(pos, ko, side)`), and a natural one-ply parent exists in the table (restore the captured stone at the ban cell, remove the capturing stone, replay the capture with the kernel → the state reappears). *Search bound: the state's own key + one ply backward, exhaustive.*
- **Class 2 — single score with a ko in its future:** entry has `L == H`, `ko == NONE`, passes 0, and the position carries no shape; a bounded BFS finds a ko-carrying state before terminal. *Search bound: depth ≤ 10 plies, ≤ 30,000 nodes per root; the witness path is recorded.*
- **Class 3 — bracketed with no ko anywhere:** entry has `L < H`, `ko == NONE`; the position carries no shape; the bounded forward search finds no ko-carrying state; the conservative one-ply backward check finds no predecessor carrying a ban. *Search bounds: forward depth ≤ 10 / nodes ≤ 30,000, exhaustive within the bound; backward 1 ply, single-capture restoration only. The backward check is weak and used as corroboration only: measured at 3×3 it never false-positives (0/1,536) but misses 1,504/1,536 (97.9%) of true ban-parent states — "no ban-parent found" is not "no ban-parent exists"; the forward check is the load-bearing half, and the 3×3 exact reverse-graph census carries the definitive numbers.*
- **Class 4 — bracketed with a ko present:** entry has `L < H` and the position carries a ko shape (fresh-start entries preferred for readability).

The 3×3 exhaustive run repeats classes 2/3 **exactly** (no bounds): ko-reachability by reverse BFS from all ko-carrying states over the whole 49,428-vertex graph; one-ply ban-parent by exact reverse adjacency.

## 4. What actually causes L < H? The correlation

The brief's question, answered at both sizes. Denominators everywhere.

### 4.1 3×3 — exhaustive over the whole table graph (49,428 entries, 184,938 edges)

Tarjan SCC decomposition (independent Python re-implementation agrees byte-for-byte on edges and SCC sizes; my entry-graph max SCC 48,602 also matches the committed T382 `--cycles` max-SCC/root-reachable-in-non-trivial-SCC figure 48,602 — the giant SCC lies wholly in the reachable subgraph, so the two graph models agree on it):

| measure | L < H entries | L == H entries |
|---|---|---|
| total | 5,408 | 44,020 |
| **in a non-trivial SCC** | **5,408 (100%)** | 43,194 (98.1%) |
| **can reach a non-trivial SCC** | **5,408 (100%)** | 43,194 (98.1%) |
| **ko-carrying state reachable (exact)** | **304 (5.6%)** | 3,280 (7.5%) |
| one-ply ban-parent (exact reverse adjacency) | 160 (3.0%) | 1,376 (3.1%) |
| mean bracket width | 6.92 | — |

Readings:

1. **SCC membership does not predict the bracket.** 100% of L<H entries sit in the single giant SCC (48,602 = 98.3% of all entries) — but 98.1% of L==H entries do too. Inside that one SCC, only 11.1% of vertices (5,408/48,602) are bracketed; 88.9% carry a single score. Same graph location, different value status — the bracket is decided by the *minimax value structure* (which cycles are value-ambiguous, i.e. where the least and greatest fixpoints disagree), not by where the state sits in the graph.
2. **Cycle-reachability is necessary but near-vacuous** (the I5 property): every L<H entry can reach a non-trivial SCC (100%); but the converse is 98% true for L==H too. "Can reach a cycle" ≫ "is value-ambiguous".
3. **Ko-reachability points the wrong way.** Bracketed entries are *less* likely to reach a ko than single-score entries (5.6% vs 7.5%). Structural reason: the value-ambiguous core (the giant SCC) is **entirely ko-free** — if any ko-carrying state were in the SCC, strong connectivity would make every SCC vertex ko-reachable, i.e. ko-reach ≥ 48,602; the exact total is 3,584 < 48,602. Kos are transient deviations *outside* the ambiguous core; the core itself carries no ko shape and no ban.

**3×3 class-3 exact census (the name-breaker):** bracketed entries that are ko-free by every exact check — no shape on the board, no ko reachable anywhere in the graph, no one-ply ban-parent — **5,072 of 5,408 (93.8%)**; fresh-start subset **3,060**, mean width 6.52 (all-L<H mean 6.92, so the ko-free bracket is not narrower). At 3×3, the bracket with no ko anywhere is the *rule*, not the exception. On the 5,072 ko-free entries the conservative one-ply check agrees with the exact reverse adjacency (it never reports a ban-parent where the exact check finds none — 0 false positives overall, cons_only = 0/1,536); its 97.9% miss rate on *ban-parent states* is why the 4×4 bounded "no ban-parent" verdicts are corroboration only, and the 4×4 bounded result is carried by the forward check alone (which found kos from 100% of sampled bracketed entries).

### 4.2 4×4 — bounded (depth ≤ 10 plies, ≤ 30,000 nodes per root), 300 per bucket, seed B (`0x5EED_2026`); seed A identical in the class-3 census

| bucket | n | cycle found within bound | ko found within bound | mean width (all) | width, cycle-found | width, no-cycle |
|---|---|---|---|---|---|---|
| fresh-start bracketed (L<H) | 300 | 292 (97.3%) | 300 (100%) | 14.35 | 14.38 | 13.38 |
| fresh-start single-score (L==H) | 300 | 255 (85.0%) | 296 (98.7%) | — | — | — |
| any bracketed entry (L<H) | 300 | 294 (98.0%) | 300 (100%) | 12.37 | 12.40 | 10.67 |
| any single-score entry (L==H, ko-free groups) | 300 | 255 (85.0%) | 298 (99.3%) | — | — | — |

Readings:

1. **Brackets reach cycles sooner** (97.3–98.0% vs 85.0% within the bound) — a weak positive correlation, and it is what the I5 property predicts (necessary-but-not-sufficient: every bracket is cycle-reachable, but at 4×4 98.5% of *all* entries are cycle-reachable globally — committed T344 I5 run, max SCC 47,429,504 = 47.9% of entries, ko_not_cr = 0/3,455,412).
2. **Ko-reach within the bound is saturated both ways** (100% vs 98.7–99.3%) — it cannot be what the bracket is *about*: the discriminator must be something else, because both classes reach kos at nearly the same rate.
3. **Width vs cycle-reach:** bracketed entries that reach a cycle within the bound are ~1–1.7 points wider on average (14.38 vs 13.38 fresh; 12.40 vs 10.67 any) — directionally consistent with "the bracket is the reachable value-ambiguous cycle's uncertainty", but small.

### 4.3 Which one predicts the bracket?

**None of the three, by itself.** In order of discrimination:

- *Cycle-reachability* — necessary (I5: 0/3,455,412 L<H entries off-cycle at 4×4; 100% at 3×3), but the positive rate on L==H is 85–98%, so as a classifier it is 85–98% wrong on the negative class. It is the best of the three only in the trivial sense that it is necessary.
- *SCC membership* — at 3×3, 100% of L<H in a non-trivial SCC vs 98.1% of L==H: near-vacuous. "In a trivial SCC ⇒ L==H" holds exactly (826/826), but that covers 1.7% of entries.
- *Ko-reachability* — at 3×3 exact it points *against* the bracket (5.6% vs 7.5%); at 4×4 bounded it is saturated both ways. Ko does not predict the bracket in either direction.

The honest answer: **the bracket is a value-structure property.** L < H marks states from which a *value-ambiguous* cycle is reachable — a cycle whose exits lead to different minimax values, so the least and greatest fixpoints disagree and the state does not determine a single score. Basic ko is one source of value-ambiguous cycles, but at 3×3 the ambiguous core is ko-free, and at 4×4 the ko-reachability signal cannot separate the classes. "The game can cycle, and basic ko does not resolve cycles" is the mechanism; "L < H" is its observable. The name should say the observable mechanism, not a red herring.

## 6. Part 2 — the renaming proposal (proposal only; the Orchestrator rules)

**The evidence to name:** L < H means the state does not determine a single fresh-start score. At 3×3 the bracket is 93.8% ko-free anywhere (exact); at 4×4 every bracketed entry reaches a ko within 10 plies (bounded) while 92.6% of bracket positions carry no ko shape — so "ko-sensitive" is wrong at the level of the *property* (ko is neither necessary nor characteristic), and its replacement must name the actual mechanism: **the game can cycle, basic ko does not resolve cycles, and the reachable value-ambiguous cycle is what makes L and H diverge.**

**Proposed name: `CYCLE-UNDETERMINED`.**

- **One-line definition:** an entry is cycle-undetermined when its stored `L` and `H` disagree — the state does not determine a single fresh-start score because a value-ambiguous cycle is reachable (the least and greatest fixpoints diverge; basic ko does not resolve cycles).
- **The I5 property reads naturally:** today "KO_SENSITIVE ⊆ cycle-reachable" (T344: 0/3,455,412 violations at 4×4). Under the new name it reads **"CYCLE-UNDETERMINED ⊆ cycle-reachable — every entry whose value is cycle-undetermined can reach a cycle"** — checkable by eye, and it states exactly what the measurement shows (100% at 3×3 exact, 0/3,455,412 at 4×4). The converse stays false and the near-vacuousness stays visible (98.5% of all entries cycle-reachable), which is the honest state of the I5 knowledge.
- **Why not the other candidates:**
  - `BRACKETED` — safe but circular: the L/H bracket *is* the bracketed property; renaming the flag "bracketed" names the observable, not the mechanism, and collides with the existing "bracket" vocabulary ([L,H] stored values).
  - `STATE-INSUFFICIENT` — accurate but vague: insufficient *for what* is only discoverable from the definition, and it does not say why (cycles).
  - `CYCLE-UNDETERMINED` names both the mechanism (cycle) and the property (undetermined value), and makes the I5 sentence a reader can verify.

## Orchestrator ruling on the renaming (Opus 5, 2026-08-06)

T385 proposed `CYCLE-UNDETERMINED`. **Ruling: adopt `BRACKETED` and `SINGLE-SCORE` instead** — the
operator's own words, and the evidence in this very document is why.

`CYCLE-UNDETERMINED` names a cause, and this row measured that the cause is **not** established:

- SCC membership is near-vacuous — `L < H` is 5,408/5,408 (100%) inside a non-trivial SCC, but so is
  43,194/44,020 (98.1%) of `L == H`. Being in a cycle predicts almost nothing.
- Ko-reachability points the **wrong way** — 5.6% for `L < H` against 7.5% for `L == H`, and the
  giant 3×3 SCC is provably ko-free (ko-reach 3,584 < 48,602).
- The row's own verdict: `L < H` is a **value-structure** property — reachable *value-ambiguous*
  cycles — not a graph-structure or ko property.

Cycles are **necessary** (I5 verified `bracketed ⊆ cycle-reachable`, 0 violations / 3,455,412 at
4×4) but demonstrably **not sufficient**. A name asserting cycles as the cause would repeat the
exact error we are correcting: `KO_SENSITIVE` was wrong because it named a cause that turned out to
be 92.6% absent. Replacing it with a second cause-name we have just failed to confirm would be the
same mistake with better manners.

`BRACKETED` / `SINGLE-SCORE` assert only what is observed — whether `L == H`. The mechanism belongs
in the one-line definition, where it can be revised as evidence lands, not in the identifier where
every future reader inherits it. It is also already the operator's working vocabulary, so the
project's documents and its owner will finally use the same words.

**Definition to carry with the flag:** *`BRACKETED` — `L < H`: the state does not determine the
value. Necessarily cycle-reachable; the sufficient condition is unknown as of 2026-08-06 (T385).*

The sweep itself stays **unperformed and queued** — ~27 `src` files, ~185 docs, ~36 register
touches, reviewed file by file, never a global `sed` (the M→L lesson). It is not urgent: the flag's
*semantics* are now documented correctly, and a rename executed carelessly costs more than a name
that is merely imperfect.
