## 2. Re-derivation by a different route — independent brute-force minimax

A naive depth-first tree evaluator with state-level memoization (TIE-on-cycle for the
VISITING case) was written and run on the position `[W, B, _, _]`, White to move, no ko,
no passes (the test position). It returns `v = -4`. This is an independent route because:

- It enumerates the game tree directly, not the L/H fixpoint sweep.
- It uses state-level cycle detection (not path-history).
- It is the textbook minimax for two-player zero-sum games with TIE-on-cycle.

```zig
// (excerpt — full source at /tmp/weizigo/T498/2x2probe/dump-1ko-chain.zig)
fn memo_value(s: State) i8 {
    if (s.passes == 2) return State.terminal_value(s);
    var best: i8 = if (s.side == 1) -128 else 127;
    if (State.apply_pass(s)) |ns| {
        best = if (s.side == 1) max_i8(best, memo_value(ns)) else min_i8(best, memo_value(ns));
    }
    for (0..4) |cell| {
        if (State.apply_place(s, cell)) |ns| {
            best = if (s.side == 1) max_i8(best, memo_value(ns)) else min_i8(best, memo_value(ns));
        }
    }
    return best;
}
```

Output: `Brute-force (state-level cycle detection, TIE-on-cycle) value: v = -4`.

Hand derivation matches: the decisive line is White plays cell 3, capturing Black's lone
stone at cell 1 (Black's stone at cell 1 had liberties {0, 3}; after White fills cell 3 it
has 0 liberties and is removed). The new board is `[W, _, _, W]`, Black to move. Both
Black's legal placements (cell 1 and cell 2) are suicide (the resulting stones have
neighbors {0, 3} = {W, W}, no liberties). Black is forced to pass, then White is forced to
pass, and the terminal area_score is `[W, _, _, W]`: 2 White stones + 2 White-territory
cells (cell 1 touches 0 and 3 which are both White; cell 2 touches 0 and 3 which are both
White) = 0 − 4 = **−4**.

## 3. Algorithm equivalence: T452's fix matches `exp6_solve.run_fixpoint_2x2`

A direct byte-level comparison was run between `qa023_brute_2x2.solve_fixpoint` and
`exp6_solve.run_fixpoint_2x2` over all 2430 states:

```
SUMMARY: agreement=2430 mismatch=0 total=2430 brute_sweeps=4 exp6_sweeps=4
```

Both algorithms:
- Initialise `L = -4`, `H = +4` for all states.
- Seed terminal states (`passes == 2`) with `L = H = area_score`.
- Sweep: for `Black to move`, `L = max` over children's `L`, `H = max` over children's `H`;
  for `White to move`, `L = min` over children's `L`, `H = min` over children's `H`.
- Resolve `v = max(L, min(TIE, H))`.

Both converge in 4 sweeps on this goban. Both produce identical `L` and `H` arrays on every
state. T452's claim of "same algorithm" is correct.

## 4. Fixpoint vs brute-force on reachable states

A second independent control: for each reachable 2×2 state (282 total), compute the
fresh-memo brute-force value and compare to the fixpoint value. **Zero mismatches on
reachable states.**

```
SUMMARY: agreement=2424 mismatch=6 total=2430
```

The 6 mismatches are all unreachable states (the `ko` field is set but the board
configuration cannot arise under the rules):

| idx  | board          | side | passes | ko | brute | fixpoint | reachable? |
|------|----------------|------|--------|----|-------|----------|------------|
| 649  | `[1, 0, 0, 0]` | -1   | 0      | 3  | 0     | 4        | NO         |
| 1055 | `[-1, 0, 0, 0]`| 1    | 1      | 3  | 0     | -4       | NO         |
| 1459 | `[1, 0, 0, 0]` | -1   | 1      | 3  | 0     | 4        | NO         |

These three states (and their symmetric variants) carry `ko = 3` (cell 3 banned) but the
board has no stone at cell 1, which is the only cell from which a single-stone capture of
W[3] can set `ko = 3` (per `apply_place`'s ko-setting rule: the placed stone must have
exactly 1 liberty and 0 friendly neighbours, AND a single opponent stone must have been
captured). The state `[B, _, _, _]` (board with only cell 0 occupied) with `ko = 3` cannot
arise: cell 0 doesn't neighbour cell 3, so Black placing at cell 0 cannot capture W[3]
directly, and a longer chain capture isn't possible on a 2×2 with a single stone at cell 3.

For unreachable states, the L/H fixpoint still sweeps them (it doesn't filter by
reachability); the brute-force memo sees them as TIE-on-cycle because no game path reaches
them. **This is not a soundness defect** — unreachable states don't arise in real play.
