## Setup

- **Board:** n points; area scores are integers in `[−N, +N]`, `N := n`
  (`src/retro.zig:90,93`).
- **Cells:** the finite index set
  `C = {(i, side, passes) : i a legal position, side ∈ {B, W}, passes ∈ {0,1}}`;
  settled positions and the two-pass terminal are **pinned** at the area score
  (`src/retro.zig:206-240`). `|C| ≤ 4·|Legal| < ∞`.
- **Value lattice:** `𝕃 = ∏_{c∈C} [−N,+N]_ℤ` with the componentwise order. A finite
  product of finite chains is a finite complete lattice (indeed distributive), with
  bottom `⊥ = (−N)_c` and top `⊤ = (+N)_c`.
- **Bellman map** `T : 𝕃 → 𝕃`, cell by cell (`src/retro.zig:254-318`): pinned cells map
  to their constant score; every other cell is
  `T(x)_c = opt_side( pass-edges, move-children )`, where `opt_B = max`, `opt_W = min`,
  and every pass edge (opponent's V1 at `i`) and move child reads one component of `x`.
  Exactly: `V1_c = opt(score_i, opt over move children)`, `V0_c = opt(opp V1, opt over
  move children)`.

## Lemmas

**Lemma 1 (monotonicity).** `x ≤ y ⇒ T(x) ≤ T(y)`. Each component `T(x)_c` is a
lattice polynomial in `x` — a composition of constants, `max`, and `min` — and
`max`/`min` are monotone in each argument on a chain; compositions of monotone maps
are monotone. ∎

**Lemma 2 (closure).** `T(𝕃) ⊆ 𝕃`: constants and child values lie in `[−N,+N]`;
`max`/`min` of in-range values stay in-range; pinned cells are fixed. ∎

Both lemmas hold for **any fixed child set**, so they cover every engine variant —
full move set, ADR-0006 eye-prune (the child set depends on the position, not on `x`),
and kill-X% (some child reads replaced by area-score constants).

## Theorem (GLOBAL.FP1)

Let `x⁰ = ⊥`, `y⁰ = ⊤`, `x^{k+1} = T(x^k)`, `y^{k+1} = T(y^k)`. Then

**(a)** `x⁰ ≤ x¹ ≤ …` stabilises in finitely many steps at the **least fixpoint**
`lfp(T)` — the engine's `L` table (`lo` quad, seeded `−N`);
**(b)** `y⁰ ≥ y¹ ≥ …` stabilises in finitely many steps at the **greatest fixpoint**
`gfp(T)` — the engine's `H` table (`hi` quad, seeded `+N`).

**Proof.** (a) `⊥ ≤ T(⊥)` since `⊥` is least; if `x^k ≤ x^{k+1}` then
`x^{k+1} = T(x^k) ≤ T(x^{k+1}) = x^{k+2}` by Lemma 1, so the orbit ascends. 𝕃 has
finite height (each component changes at most `2N+1` times), so the chain stabilises:
`∃M, T(x^M) = x^M` — a fixpoint. It is least: for any fixpoint `z`, `⊥ ≤ z`, and by
induction `x^k = T^k(⊥) ≤ T^k(z) = z`, so `x^M ≤ z`. (b) is the order-dual: `⊤ ≥ T(⊤)`,
the orbit descends, stabilises, and bounds every fixpoint from above. ∎

## Consequences and hand-offs

- **Sweep order is irrelevant.** The engine's in-place, stone-count-descending,
  multi-threaded sweep is a *fair chaotic (asynchronous) iteration* of `T`; for a
  monotone map on a finite lattice, fair chaotic iterations from `⊥` (resp. `⊤`)
  converge to the same `lfp`/`gfp` (Bertsekas 1983). This licenses
  `GLOBAL.ADR0012-PAR`; the zero-change full sweep is then a valid fixpoint certificate.
- **Finite termination** is the content of `GLOBAL.FP3` (separate row): the
  finite-height argument in (a)/(b) is exactly the hand-off. The sweep *count* is a
  measurement (`4x4.M2`), not the theorem.
- **Multiple fixpoints are expected**, not anomalous: on a cyclic game graph
  `lfp < gfp` in general and Tarski's theorem makes the whole fixpoint set a complete
  lattice — consistent with `GLOBAL.B1-MULTIFIX` (re-converge from `+N` lands above
  canonical) and with `GLOBAL.B1-AUDIT` (a fixpoint landed on from another seed is not
  thereby least). The choice of fixpoint *is* the cycle rule (ADR-0009, Decision 2).
- **Out of scope (not closed here):** the per-goban *empirical* acceptance rows
  `4x4.FP1`, `4x3.FP1`, `4x4.FP1-C1` (seed), `4x4.FP1-C2` (zero-change) — this theorem
  is structural and goban-independent; whether a specific build was actually seeded
  from `±N` and terminated on a zero-change sweep is a log/artifact check (punchlist L1).
  `4x4.FP1-C3` (V0/V1 Bellman identities) already PASSES and is unaffected.
