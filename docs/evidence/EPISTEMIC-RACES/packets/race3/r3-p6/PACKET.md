# Race 3 · Packet R3-P6 — "the certificate, not the program"

*Exam item for EPISTEMIC-RACES race 3 (prior-art mapping). Below is a plain-language description of the project's milestone M6 goal. Identify the prior art: the result, the team, and the citation, and what the literature offers that the project has not imported.*

## The description

The project's milestone M6 wants more than a strong program: it wants a certificate — a
machine-checkable argument that the table is the answer, that every reachable position's
value is the exact game-theoretic value under the written rules, so the program becomes a
reference other software can be checked against. That shape of proof exists for a complete
two-player game with draws: a team proved the game is a draw from the start position with
perfect play, by combining a massive backward-built database of endgame positions with search
over the opening. It is the largest complete game solved to date and the exact prior art for
M6's certification goal — the part the project has not imported is everything that made the
proof checkable rather than merely believed.

## Task

1. **Name the prior art** (the game, the result, the team, and the year) and give the
   canonical citation.
2. In 2–4 sentences: what does the literature offer that the project has not imported?
