# Race 3 · Packet R3-P5 — "what is already known at 5×5?"

*Exam item for EPISTEMIC-RACES race 3 (prior-art mapping). Below is a plain-language description of an open problem on the project's frontier, together with what is already known about it. Identify the prior art: the person and result, the year, and what the literature offers that the project has not imported.*

---

## The description

The project's frontier is 5×4 and 5×5 — the next goban sizes after the completed 4×4 table.
Before committing to the attempt, the question is what is already known at exactly that size:
has the empty 5×5 goban been solved exactly, and by what method? The answer is the largest
empty goban solved to date: it was solved in 2003 by a solver built on a form of the guided
search described in the preceding packets, using retrograde techniques and several ko-rule
variants, and the result is still standing. For the project this is a bound, not a
curiosity: the go/no-go memo for 5×5 must be costed against what that solver already achieved,
and its techniques are prior art to import rather than rediscover.

## Task

1. **Name the prior art** (the person, the solver, and the result, with the year) and give
   the canonical citation.
2. In 2–4 sentences: what does the literature offer that the project has not imported?
