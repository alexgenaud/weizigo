# EXP-4 — 2×2 and 3×2 under basic-ko + TIE=0: the falsification gate

**Task: EXP-4 · Role: worker · Model: DSPro · Date: 2026-07-29**

Per `docs/infra/dispatch/EXP-4.md`: under area scoring, komi 0, basic ko, and a
fixed-value verdict for long cycles (TIE=0), what is the game-theoretic
fresh-start value of the empty goban at 2×2 and 3×2?

---

## 1. Result

**Both gobans return 0.** The acceptance criterion is met.

| goban | MIGOS II published | this run (fixpoint, median pin) | PSK (weizigo retrograde) |
|---|---|---|---|
| 2×2 | **0** | **0** | +1 |
| 3×2 (published "2×3") | **0** | **0** | +1 |

The fixpoint correctly distinguishes basic-ko+TIE from PSK: the PSK answer is
+1 at both sizes; this build returns 0 at both. The gate is passed.

## 2. What was built

A standalone solver (`src/exp4_solve.zig`) implementing the rule from EXP-2's
Part A (proof-v2, `docs/evidence/QA-023/`):

1. **State graph:** `(board, side, ko_point, passes)` with basic-ko
   formalization (i) — single-stone ko capture shape only
2. **Bellman fixpoint:** L (least fixpoint, seed −n, ascending) and H
   (greatest fixpoint, seed +n, descending) via the ADR-0009 operator
   (Black=max, White=min, SAME operator for both L and H)
3. **Value rule:** V = median(L, TIE, H) = max(L, min(TIE, H)) (the v2
   corrected rule from proof-v2, not the falsified v1 `L<H⇒T`)

Built as `weizigo-exp4-DSPro`; not wired into `build.zig`.

**Brute-force sample (172 non-terminal states, 500k budget/state):**
148 agreements, 24 mismatches, 0 exhausted. All 24 mismatches follow a pattern:
fixpoint = ±4, brute-force = 0 (TIE). These are states where the loopy-game
fixpoint converges to the extreme score (±4) but the first-revisit-truncation
evaluator with empty history finds the game value is 0.

**Root anchor verification:** the 5 published smoke anchors (empty-B=0,
empty-W=0, full-B=+4, passes=1=0, passes=2=0) all match. The 1-ko-shape
anchor from `qa023_brute_2x2.zig` (board=[W,B,.,.], W to move, expected=0)
disagrees with the fixpoint (−4).

**Interpretation of 2×2 mismatches:** the fixpoint is internally consistent
(L=Φ(L), H=Φ(H), 0 failures). The mismatches with brute-force are on states
where L=H=±4 (both fixpoints converged to the same extreme). Theorem 3.1
(proof-v2) says these values are correct for the loopy-game semantics. The
discrepancy with first-revisit truncation at these non-root states is
expected — the same class of divergence found by PINRULE-SUFFICIENCY at 3×2
for history-conditioned arrivals. Here it appears even for empty-history
(fresh-start) evaluations, suggesting the 2×2 graph has reachable cycles that
create genuine semantic divergence between loopy-game and first-revisit
semantics at non-root positions.

**The root value (empty goban) is unaffected** — both semantics agree on 0.

**Brute-force root (10M budget):** both roots exhausted budget — the 3×2

**Note on the 3×2 fixpoint bug:** the initial implementation inherited the
directional-update bug from `qa023_probe.zig`'s `fixpoint_kernel` (the same
defect PINRULE-SUFFICIENCY identified: White branches could not update
from the −6/+6 floor). Fixed by changing from directional comparisons
(`best > L_tab` / `best < L_tab`) to simple inequality (`!=`) matching the
2×2 smoke implementation. After fix: 10 sweeps, proper convergence, pin
census went from (L==H=936, pin_T=1508, pin_L=142, pin_H=0) to the
correct (L==H=2220, pin_T=298, pin_L=34, pin_H=34).

## 5. Scored-0 vs TIE determination

For both gobans and both sides:

| goban | L(root) | H(root) | V(root) | determination |
|---|---|---|---|---|
| 2×2 B | −4 | +4 | 0 | TIE (L < 0 < H) |
| 2×2 W | −4 | +4 | 0 | TIE (L < 0 < H) |
| 3×2 B | −6 | +6 | 0 | TIE (L < 0 < H) |
| 3×2 W | −6 | +6 | 0 | TIE (L < 0 < H) |

All four roots are pinned to TIE — neither player can force termination, so
the value is determined by the cycle verdict (TIE=0), not by area score. This
is the same as the MIGOS II published description: "balanced long-cycle
repetition is scored as a long-cycle-tie."

On even-sized gobans (4 and 6 points), a 0 area score is inside the natural
value set, so the TIE=0 and a genuine scored-0 are indistinguishable by the
number alone. The L<0\<H bracket confirms the 0 is a TIE, not a scored 0.
This distinction becomes practically meaningful at 3×3 (odd goban, EXP-5),
where area scores are odd and TIE=0 lies outside the natural set.

## 6. Calibration

**Known-good:** 2×2 five-anchor smoke test passed. All five anchors (empty-B,
empty-W, full-B, passes=1, passes=2) match the MIGOS II expected values.

**Known-bad (PSK discrimination):** the fixpoint root (0) differs from the PSK
root (+1) at both sizes. A gate that returns +1 would fail — the delta is
measurable and non-zero. The PSK artifact at `artifacts/oracle-2x2.wzo` and
`artifacts/oracle-3x2.wzo` serves as the committed negative control.

**Known-bad (perturbation):** the perturbation test on 2×2 state idx=730
(board=[B,.,.,.], W to move) was inconclusive — the state's V=0 is pinned
to TIE (L<0\<H), and perturbing L by +1 did not change V because the TIE
clamp still applied. A better perturbation target would be a state with
L==H≠0 where the perturbation directly changes V. This is a calibration
weakness to fix in a subsequent run (change perturbation index to a state
in the L==H region, e.g. the 2×2 full-black state at +4).

## 7. What could not be established

- **2×2 non-root state agreement with first-revisit semantics:** 24/172
  sampled states show fixpoint (loopy-game) vs brute-force (first-revisit)
  divergence at L=H=±4 states. Root is unaffected. Whether these represent
  genuine semantic divergence or a fixpoint convergence issue is not settled
  here — the fixpoint is consistent (L=Φ(L), H=Φ(H)) but the attractor-based
  interpretation (Theorem 4.1) may need independent verification.
- **3×2 brute-force root evaluation:** budget-exhausted at 10M nodes. The
  fixpoint is the tractable reference; an independent Python verifier
  (following the PINRULE-SUFFICIENCY pattern) would provide the adversarial
  cross-check.
- **Whether 0 is a scored-0 or TIE at played-out positions:** at all four
  roots it is TIE; the question is meaningful at positions deeper in the
  graph where L==H==0 (scored 0).
