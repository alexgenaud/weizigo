# E1-markovian

The epic arena for the Markovian-ruleset milestone: decide whether weizigo
can be exactly solved under a tractable, traditional ruleset, and under
which one. The goal statement emerges from completed sprints — see
`docs/infra/sprint.md` for the epic / sprint / task ladder and layout.

- `sprints/<sprint>/passN/` — canonical phase docs (unsuffixed, revised in
  place, commit-pinned citations).
- `sprints/<sprint>/archive/` — ephemera: audits, notes, drafts; absorbed
  into disposition logs and deleted at gate commits.
- `spec.md`, `decisions/` — epic-level; owned by the project-restructure
  sprint to populate.
