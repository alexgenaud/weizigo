| 1 | **G4's start-time floor cannot deliver the edge-table's pid-reuse guarantee, and a dead anchor without `--since` has no floor at all.** The edge table promises "pid reused since spawn → never claimed: member start time must be ≥ the `--since` floor"; but `--since` is optional and its default is defined only for a live anchor ("Default when the anchor is live: the anchor's own start time"). `since` = spawn/run-start time, which precedes the anchor's death — a pid (or sid) recycled *after* death starts after the run start, passes the floor, and the sid term (`sid(P) ∈ {anchor}`) claims the recycled session leader's whole new session. The floor excludes only pre-spawn processes; the named failure mode is post-spawn recycling.
