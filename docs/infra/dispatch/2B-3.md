# 2B-3 — history-pair generation at 3×2

**Goal:** for each sampled 3×2 state, enumerate **k distinct bounded arrival histories** reaching it (at least one trivial/fresh-start and several non-trivial). The visit-SET of each history is what QA-023 is independent of.

**Machinery:** `play_arrival` already exists in `src/qa023_probe.zig` — reuse it.

**Second vacuity guard (acceptance):** the count of pairs whose visit-SETS differ must be > 0, or the test is vacuous (same trap as 2×2) — escalate.

**Deliverable:** `docs/evidence/QA-023/history-pairs-3x2-2026-07-29.md` — N states, K histories each, total pair count, the visit-set-difference count. **Acceptance:** non-zero cycle-eligible states with ≥2 visit-set-distinct histories, or an escalate recommendation.

**Build/run:** through `tools/runner`; ≤1h; heartbeat; node budget that fails loudly.

**Read first:** `docs/infra/dispatch/EXP-2B.md`, `docs/evidence/QA-023/reference-semantics-2026-07-29.md` (2B-0).

**Hazard:** never run unfiltered `zig test src/qa023_probe.zig` (collects the brute's exponential tests). Use `--test-filter`. `tools/runner` guards RSS only; node budget is the primary guard.
